# TripSplit v0.1 — 本地交互原型

这是可运行的 React + TypeScript + Vite 手机优先原型，不是已连接 Supabase 的多人在线版本。

## 本地运行

```bash
npm install
npm run dev
```

打开终端显示的网址。生产构建：`npm run build`。

## 已实现

- 首次输入昵称；本机浏览器保存用户资料
- 创建多个房间、设置房间结算币种
- 房间邀请码（仅同一浏览器数据内有效）
- 添加、编辑、软删除支出；选择付款人及均分成员
- 多币种手动汇率（每笔账目固定保存汇率）
- 计算净余额、生成建议转账、记录还款
- 账目操作历史、房间归档、CSV 导出
- PWA manifest、移动端布局

## 尚未实现（不要用于真实多人共享账目）

- Supabase 匿名认证及持久化云端数据
- 跨设备邀请码、真正的多人实时同步
- 数据库 RLS、事务、服务端审计日志
- 可靠的离线缓存和离线写入
- 自定义金额/比例分摊（当前仅均分选定成员）
- 房主权限、房间成员移除

数据存储在浏览器 localStorage，清除网站数据可能永久丢失。不要用于真实财务数据。

## 下一阶段

建立 Supabase 项目、部署安全 SQL 迁移（包括匿名用户的 RLS、邀请兑换 RPC、账目事务函数及审计触发器），再替换本地存储层。
