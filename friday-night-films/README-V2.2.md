# V2.2 — Movie Night Archive

1. In Supabase > SQL Editor, run `supabase-v2.2-archive-migration.sql` once.
2. Replace `index.html`, `style.css`, and `app.js` in GitHub with the V2.2 files.
3. After a movie night, click **Watched it? → Archive** on the movie card.
4. Pick the watched date, optional 1–5 group rating, and an optional one-line memory.
5. The film leaves the current ballot and appears under **Previous nights**. Realtime sync remains enabled.
