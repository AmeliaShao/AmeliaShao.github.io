# Friday Night Films V2.1

New: Attendants section with name, emoji avatar, optional floating note, live count, remove button, and Supabase realtime sync.

## Upgrade
1. In Supabase > SQL Editor, run `supabase-v2.1-migration.sql` once.
2. Replace `index.html`, `style.css`, and `app.js` in GitHub with these V2.1 files. (`config.js` is unchanged.)
3. Wait for GitHub Pages to deploy, then hard refresh.
