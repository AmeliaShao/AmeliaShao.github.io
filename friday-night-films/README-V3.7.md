# Friday Night Films V3.7

Adds a permanent **Start next week →** button to Tonight's Lineup.

Use it if a film was already archived before the weekly-reset flow was triggered. It opens the same rollover confirmation and performs the V3.6 reset: remaining candidate votes reset, candidates roll forward and increment weeks waiting, current attendees become inactive, lineup fields and saved weekly pick clear, and the ballot date advances to the next Friday.

No new Supabase migration is required beyond the V3.6 migration.
