# V2.8

Run `supabase-v2.8-comments-reviews-migration.sql` once in Supabase SQL Editor, then replace `index.html`, `style.css`, and `app.js` on GitHub Pages.

Changes:
- `Rate & review` is always visible.
- Archive no longer asks for a single shared memory.
- Each attendee can add/edit a short personal review together with their star rating.
- Current candidates have a compact comment-count button (`💬 n`) that opens a focused movie thread, keeping the card grid clean.
